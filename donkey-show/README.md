# שני חמורים על הבמה — קליפ אנימציה

**גרסה נוכחית: חבילת הפקה v2.** במה בכחול לילה, וילונות אדומים ואורות זהב. קאסט קבוע של שבע דמויות: חזי (טורקיז), שוקי (חרדל), פסנתרנית, קונטרבסיסטית, מתופפת, גיטריסט וצב מנהל במה.
יש שני גאגים חוזרים בלבד: האיחור של שוקי ברבע פעימה, שאחריו הוא מתקן בחיוך, ומבט הצב בשעון. מחוגי השעון מתקדמים בכל פעם.
הסיום: סולו גיטרה מוגזם שבזמנו החמורים קדים, והצב מרים את שלט השעון.

קליפ 2D מינימליסטי: שני חמורים עסקיים ששרים ורוקדים על במה צנועה, עם תזמורת של שלוש קופות משועממות.
הדמויות בנויות ב-SVG עם איברים נפרדים (גוף, ראש, שתי אוזניים, גבות, עיניים, לסת, זרועות, אמות, ירכיים, שוקיים, כפות רגליים, מיקרופון), והאנימציה מחושבת בקוד בכל פריים. אין כאן הזזה של תמונת רקע.

## הרצה
פותחים את `index.html` בדפדפן (Chrome מומלץ). אם `audio/song.mp3` קיים, השיר נטען אוטומטית. אחרת אפשר לטעון MP3 או WAV מהכפתור.
- **נגן / השהה / מההתחלה**: זמן האודיו הוא שעון האנימציה, גם בהשהיה ובקפיצה בסרגל.
- **עריכת זמנים**: לכל שורה יש זמן התחלה, זמן סיום ודובר. כל משחק, מבט וגאג מעוגן לשורה, כך שהזזת שורה מזיזה גם את המשחק שלה.
- **תזמון בהקשה**: מסמנים "מצב הקשה", מנגנים, ולוחצים `J` בתחילת כל שורה ו-`K` בסופה.
- **ייצוא וייבוא** של קובץ התזמון ל-JSON. השינויים נשמרים גם בדפדפן.

## רינדור ל-MP4
```
node tools/render.js --out out/clip.mp4                        # כל השיר, 1920x1080, 30fps, עם האודיו
node tools/render.js --from 0 --to 15 --out out/sample.mp4     # קטע
node tools/render.js --stills 12.4,33.9 --outdir out/stills    # תמונות בודדות
node tools/render.js --check                                   # בדיקה: אוזניים או דמויות שיוצאות מהפריים
```
דרוש Playwright (Chromium) ו-FFmpeg. הסקריפט מצייר כל פריים בזמן t = n/30 ומצמיד אליו את אותו קטע אודיו.

## מקור התזמון — בכנות
- הזמנים ב-`src/timing.js` נוצרו ב-`tools/make_timing.py`: השירה הופרדה מהשיר (מודל UVR-MDX-NET-Voc_FT), חולקה למשפטים לפי עוצמה והותאמה לסדר השורות במילים. **לא הופעל זיהוי דיבור**, ולכן גבולות בין שורות עלולים לסטות. מומלץ לעבור עליהם באוזן ולתקן בעורך.
- תנועות הפה נקבעות לפי עוצמת ערוץ השירה המופרד (מעטפת של 60 ערכים לשנייה), לא לפי פונמות. זה **לא** סנכרון שפתיים מדויק.
- שיוך שורות לדוברים נקבע לפי היגיון הדיאלוג במילים, ואפשר לשנות אותו בעורך.
- קטע הסיום האינסטרומנטלי (בערך 103–158 שניות) מומש כגאג "הדרן": הלהקה לא מפסיקה לנגן.

## קבצים
- `src/rig.js`: בניית החמורים ותנועתם (IK לרגליים ולזרועות, לסת, עפעפיים, אוזניים עם השהיה).
- `src/scene.js`: הבמה, הווילונות, הנורות, הכוכב והתזמורת.
- `src/choreo.js`: הכוריאוגרפיה כפונקציה טהורה של הזמן.
- `src/app.js`: הנגן, הכתוביות, המצלמה ועורך הזמנים.
- `source/suno-lyrics-hebrew-nikud.txt`: קובץ המילים המנוקד המקורי, ללא שינוי. הכתוביות מוצגות בלי ניקוד.
