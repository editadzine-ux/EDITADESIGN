# Edita · editadesign.co.il

האתר של Edita: מיתוג, אפיון, עיצוב ופיתוח אתרים, ותוכן לרשתות.

## מה יש כאן
- `index.html` הוא העמוד הראשי.
- `js/` מכילה את הקוד שמריץ את האתר (כולל React).
- `assets/` מכילה את הסרטונים, צילומי המסך והתמונות.

## איך מעלים לשרת
מעתיקים את **כל** התוכן של הריפו (index.html והתיקיות js ו־assets) לתיקיית האתר בשרת, בדרך כלל `public_html`. אין צורך בהתקנה או בבנייה.

## תצוגה מקומית
פותחים טרמינל בתיקייה ומריצים `python3 -m http.server`, ואז נכנסים ל־http://localhost:8000.

## וורדפרס (editadesign.co.il)
האתר מוצג דרך התוסף `wordpress/edita-site.php` (מותקן ב־wp-content/plugins/edita-site). התוסף מוריד את התוכן העדכני של הריפו הזה לתיקייה `site/` שלו. השבתת התוסף מחזירה את עמוד הבית הקודם.
